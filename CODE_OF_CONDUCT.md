# Code of Conduct

We aim for a respectful, practical, and privacy-conscious collaboration space.
Be constructive, assume good faith, and discuss technical disagreements without
personal attacks, harassment, or discrimination.

Do not post private artwork, personal files, credentials, API keys, or screenshots
that expose private information. Security concerns follow `SECURITY.md`.

Maintainers may remove content or restrict participation when this code of
conduct or the repository's privacy boundaries are breached. This policy is
intended to keep contributions useful and safe; it does not replace the hosting
platform's own rules.
